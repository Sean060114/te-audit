# 与 PolyA、Carey 2021、"Fake IDs" 的判据逐项对照

> 目的：把三篇在位点级做过工作的文献，与本项目的判据放在同一张表上比。比完要能回答
> 两个问题——哪一条我们其实在重复，哪一条确实没人做过。**结论比预想的窄。**

## 一、三篇各做了什么（精确版）

### PolyA（Wheeler lab，bioRxiv 2021，预印本）

对**每个碱基位置**计算竞争注释的置信度，用 DP 求最大置信路径，由路径的变化点定边界。

- 全序列置信度：对竞争集合 `Q = q1..qn` 做后验归一化，均匀先验下 `P(qi|t) ∝ P(t|qi)`。
  比对分数是 log-odds 的缩放版，因此等价于对分数做 softmax。
- **位置级**：窗口 `w = 31`，`s = max(1, j−15)`、`e = min(L, j+15)`，只统计覆盖该窗口的
  子比对；位置 `j` 的置信度取**所有覆盖它的窗口的未加权平均**。
- **DP**：行=候选注释、列=位置，只在对齐覆盖处有值（稀疏矩阵）；转移惩罚
  `tm = 1e-55`、`ts = 1 − tm − tms`、`tss = 1 − tms`——**换注释被重罚，进出 skip
  state 罚得轻**。另有 STR（ULTRA 的逐位置 log-odds）作为额外候选。
- **skip state**：允许"这里不给注释"，并给它一个"special default score"，使其能胜过低
  质量候选。
- 输入：**alignment 集合 + 打分矩阵与 gap 参数**（本文用 cross_match、Repbase
  RepeatMasker Edition、25p41g、gap −25/−5）。**不直接吃库，也不吃 gff。**

### Carey, Patterson & Wheeler 2021（Mobile DNA 12:4）

用**生物学重复**检验 subfamily 标签的可复现性，并给出置信度。

- 置信度（Eq 10）：`Conf(qi|t) = 2^(score(t,qi)/λ) / Σj 2^(score(t,qj)/λ)`
  —— 对竞争 subfamily 的得分做**底 2 的 softmax**，`λ` 由 `esl_scorematrix` 从打分矩阵推断。
- 配对层面取两者较小值：`m = min(Conf(q̂|t1), Conf(q̂|t2))`。
- 真值代理：片段重复（16,962 对，均 >1 kb、≥90% 一致，只取单次重复）与人–黑猩猩同源 TE。
- 数字：Alu 12.4%、L1 14.1%、L2 15.7%、MIR 10.4%、MLT 6.7% 被判为不同 subfamily；
  **concordant 对置信度中位 73.4%，discordant 52.8%**（KS `P = 9.4e-116`）。
- 建议（原文）：建库时用可靠性度量决定"细分到多细"；**注释流程应输出 confidence，
  下游工具应纳入这种变异性**。

### "Fake IDs?"（Hassan & Adelson, Genome Biology 2023, PMC10641963）

用基因注释查 TE 标错。

- 判据：`bedtools intersect -a repeats.bed -b cds.bed -wo -f 1.00`，即 **100% 的 TE 落在
  CDS 内**，并排除简单重复。
- 规模：非哺乳类脊椎动物数百例；集中在斑马鱼与非洲爪蟾；hAT 与 Ty3/Gypsy 为主。
- 人工核验 28 条"自主型 hAT"的标准：**双侧 TIR 与 TSD + 完整 ORF + DDE/RW 催化残基**，
  侧翼各延伸 1,000 bp 找 TIR/TSD。
- 建议：**在基因模型注释的最后一步加一次"基因模型 vs TE 同源性"筛查**。

## 二、逐项对照

| 维度 | PolyA | Carey 2021 | Fake IDs | 本项目 |
|---|---|---|---|---|
| **判定对象** | 每个碱基位置 | 每条序列（整条） | TE 注释行 × CDS 注释行 | 每个元件（注释的一行） |
| **竞争集合** | 同一库内多个 consensus 的 alignment | 同一库内多个 subfamily | 无（两种注释类型对撞） | **两个流程的标签 + 结构复算 + 基因模型** |
| **置信度形式** | 逐位置 softmax + 窗口平均 | 整条 softmax（Eq 10） | 无（二值重叠） | **无分数：三档 + 失败项** |
| **"判不了"如何处理** | skip state（可判为无注释） | 置信度接近 50% ＝接近随机，但仍给标签 | 不处理 | **C 集 + 归因（冲突／无第二来源／边界不可定位）** |
| **边界** | DP 路径变化点（推断） | 不涉及 | 不涉及 | **不推断**：由字段给出，用 TSD/motif/两翼复算**验证** |
| **需要的输入** | alignment + 打分矩阵 | RepeatMasker `.out` + Repbase | RepeatMasker + 基因/CDS bed | **`intact.gff3` + 基因组 fa + 另一流程 gff3 + 基因模型 gff3** |
| **需要商业库** | 是（Repbase） | 是（Repbase） | 部分（Repbase 用于人工核） | **否** |
| **能否发现"库整体错"** | 不能 | 不能 | 能（但只看 CDS 重叠一种模式） | 能（跨大类：AnacB 的 TIR↔LTR） |
| **是否校准解析层** | 不涉及（吃 alignment） | 不涉及（吃 `.out`） | 不涉及（吃 `.out` 与 bed） | **是核心内容** |

## 三、三条关键发现

### 3.1 softmax 类置信度测的是"库内相对优势"，不是"绝对正确性"

PolyA 与 Carey 的置信度分母都是**竞争候选之和**。这个分母永远存在——**即使库里没有
一个正确的标签，softmax 仍会归一化出一个数值，而且可能很高**。

举个具体情形：一段实际是 LTR/Gypsy 的序列，被一个把 Gypsy 建成 AnacB 的库去注释。
库内只有 AnacB 候选，softmax 给出 AnacB 置信度接近 1.0。**置信度高，标签错。**

Carey 的证据是统计相关而非保证：discordant 对中位置信度 52.8%（接近随机的 50%），
concordant 73.4%。这说明"错的时候分数往往低"，但**不排除"错而分数高"**——而 52.8%
与 73.4% 的分布必然有重叠，论文没有报告重叠部分的比例。

→ **本项目处理的恰恰是这一类**：23 条 AnacB 冲突里，MSU 的库把 LTR 结构标成 DNA/TIR。
库内 softmax 无法发现这种错，因为它不知道还有另一个库。

**更结构性的一点：de novo 流程的库是自己建的。** EDTA、HiTE、RepeatModeler 都是先用
基因组挖出候选、再聚成 consensus、再用这个 consensus 回注释同一个基因组。元件与它的
consensus 来自同一批序列，比对分数天然高，而 softmax 的分母里**不存在真正的竞争
者**——每个元件最像的永远是它自己的 consensus。

结果就是：**在 de novo 流程的输出上，库内置信度是一个结构性虚高的量。** 它高不是
因为标签对，而是因为库和元件同源。这不是 PolyA 或 Carey 的缺陷（他们的场景是拿
Repbase 这种外部库去注释，库与元件不同源），而是**把这个方法搬到 de novo 流程上会
失效**。

这条也解释了本项目为什么必须换证据类型：在同一份 de novo 输出内部，无论怎么算置信度，
都跳不出"自己比自己"的循环。

### 3.2 PolyA 的 skip state 已经在做"判不了"，与我们的 C 集**同源**

这一点必须承认：PolyA 的 skip state 允许"此处无注释"，并给它一个能压过低质量候选的
默认分数。这与我们"把 C 集单列"是同一种认识的产物——**都承认二元对错装不下现实**。

差别在**归因**：skip state 只说"没有足够好的候选"；我们的 C 集说"因为边界落在 TA
微卫星里、TSD 有多个等效位置，换参数也定不下来"。前者是**结论**，后者是**下一步动作**。

### 3.3 三者都不碰解析层，而这是我们唯一没有对手的地方

三篇的输入都是**格式规范**的东西：alignment、RepeatMasker `.out`、bed。`.out` 的 9 列
含义固定，不存在"第 4 列到底是谁的 identity"这种歧义。

EDTA 的 `intact.gff3` 不是：一个元件占 6 行、`motif=` 按元件方向书写且负链要交叉、
`TSD=` 第三段是打分不是长度、TIR 的元件坐标不含 TSD 而 LTR 的含。**不校准，评测会把
解析错误当成生物学错误。**

本项目实测：约定错时 8%、约定对时 99%（LTR 的 TSD）；`motif` 漏了负链 rc，靠
"406/420 正反两读同时成立"把错误藏到 97.6%。**这类错误没有任何现有工具会报。**

## 四、我们还能站住的（收窄后的三条）

| # | 主张 | 与谁不重叠 |
|---|---|---|
| 1 | **跨来源、跨证据类型的位点级登记**（结构复算 + 另一流程标签 + 基因模型） | PolyA/Carey 都是**库内**竞争；Fake IDs 只看一种重叠模式 |
| 2 | **解析层校准作为评测前置条件** | 三篇都不涉及；它们吃的格式本身没有歧义 |
| 3 | **"判不了"的归因分类**，而非单一分数 | PolyA 有 skip state 但只给结论；Carey 只给分数 |

**必须放弃的一条**：「首创位点级判定」。PolyA 已经做了，而且有 DP 与位置级平滑，做得
比我们细。

**也不该声称的一条**：「我们的方法更准」。没有 gold standard，无法比较准确率。只能说
解决的是不同问题。

## 五、写作时怎么引

- 引 PolyA 时说清差别：**它裁决库内竞争，需要 alignment 与打分矩阵；我们不裁决，
  只登记跨来源证据**。不要写"PolyA 不能处理位点级"——它恰恰做了位点级。
- 引 Carey 时用它撑腰：**"该报不确定性"是 2021 年就有的主张**，本项目是对这个主张的
  一种工程化回应（给出可归因的类别而非分数）。这样写比声称新颖安全得多。
- 引 Fake IDs 时承认方法同源：**"用基因注释查 TE 标错"不是我们发明的**，差别是我们
  把它当分级依据并配了零模型（随机窗口 11%、28 条 32%、一致组 16%）。

## 六、如果被质疑"这不就是 PolyA 吗"

四句，按顺序：

1. PolyA 的输入是 alignment 集合，需要打分矩阵与 gap 参数（λ 只用于 dust 校正，
   不进置信度的指数）；本项目的输入是注释文件本身，不做比对，只用序列做字符串级
   复算（TSD 相等、motif 位置、两翼相似度）。
2. PolyA 在**一个库内部**裁决竞争候选；本项目处理的是**两个库对同一坐标给出不同
   类别**，这类冲突不在 PolyA 的问题空间里。
3. PolyA 输出连续置信度；本项目输出可归因的类别——因为下游要做的动作不同
   （改标签 / 补证据 / 标记为不可用）。
4. PolyA 依赖 Repbase；本项目在本条件下拿不到任何商业库，这也是为什么必须换证据
   类型而不是换打分方式。

     不敏感**。→ 两篇的百分数不可放在同一张图或同一阈值上比较。
