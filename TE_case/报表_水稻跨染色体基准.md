# 水稻跨染色体基准：Chr1 的结论是否代表全基因组

**日期**：2026-11-17
**数据**：IRGSP-1.0 Chr1 + Chr12 合并成**一次** EDTA 运行（70,802,779 bp，两条序列，一套库）
**目的**：回答上一个报告的遗留问题——Chr1（占基因组 11.6%）上的数字，能不能外推。

---

## 0. 先更正我自己的一个数字口径

我在设计这次运行时说"Chr1 的 MSU 密度 36.49%、Chr12 是 47.35%"。**那两个数是逐条相加（`bp_sum`）算的，
不是区间并集（`bp_union`）**——嵌套元件被重复计入了。正确的并集值是：

| 染色体 | 逐条相加（我当时用的） | **区间并集（正确）** | 差 |
|---|---:|---:|---:|
| Chr1 | 36.49% | **29.02%** | 7.5 pp |
| Chr12 | 47.35% | **38.27%** | 9.1 pp |

结论方向不变（Chr1 低、Chr12 高），而且**相对差距更大**：38.27 / 29.02 = 1.32 倍，
而不是 47.35 / 36.49 = 1.30 倍。但绝对值我说错了 7–9 个百分点。
这正是这个项目里第二次栽在同一件事上（第一次是 C4 的分母）——**报密度前先确认是哪种口径**。

---

## 1. 设计：为什么把两条染色体放进同一次运行

EDTA 是 de novo 建库，**输入越大库越全，同源注释的召回天然越高**。
若把 Chr12 单独跑，召回差异就同时混着"密度效应"与"库大小效应"，无法归因。

两条合并后共用一套库，两个效应被分开；代价是多花 43 Mb 的计算时间，收益是解释干净。
**顺带 Chr1 变成一次独立重复**——同一序列、两次独立运行，可以直接量化 run-to-run 波动，
而这一点此前从未测过。

参数：EDTA v2.2.2，`--species Rice`，16 线程，12:00–14:04（124 分钟）。
LTR 阶段仍触发双 `.mod.mod` 前缀，脚本自动改名修复后完成（`LTRlib.fa` 1,545,582 B）。

---

## 2. 总体覆盖：密度升高，召回没有下降

| | Chr1 | Chr12 |
|---|---:|---:|
| 染色体长度 | 43,270,923 | 27,531,856 |
| MSU 重复（并集） | 12,558,926（29.02%） | 10,536,792（38.27%） |
| EDTA 注释（并集） | 17,057,492（39.42%） | 13,353,268（48.50%） |
| 交集 | 10,923,034 | 9,206,317 |
| **碱基召回** | **87.0%** | **87.4%** |
| **碱基精确率** | **64.0%** | **68.9%** |
| EDTA 独有 | 6,134,458（36.0%） | 4,146,951（31.1%） |
| MSU 独有 | 1,635,892（13.0%） | 1,330,475（12.6%） |
| MSU 不可归类占比 | 10.0% | 6.6% |

**核心结论 1：重复密度升高 9.25 个百分点，召回率只动了 +0.4 pp（87.0 → 87.4）。**

我此前的担心是"高密度 → 嵌套更多 → 建库更易塌缩 → 召回下降"。**这个担心不成立**，
至少在水稻这两条染色体之间不成立。精确率反而高了 4.9 pp。

需要说明的是，Chr1 的 MSU 不可归类量（10.0%）高于 Chr12（6.6%），这会**压低** Chr1 的召回
分母解释空间；但两者差距只有 3.4 pp，不足以解释"召回几乎相同"。

## 3. 三合桶：LTR 组是唯一可比粒度，且跨密度稳定

| 染色体 | 组 | MSU bp | EDTA bp | 交集 | 召回 | 精确率 |
|---|---|---:|---:|---:|---:|---:|
| Chr1 | LTR | 6,196,278 | 6,433,119 | 5,038,566 | 81.3% | 78.3% |
| Chr1 | DNA | 5,360,154 | 7,043,430 | 3,300,751 | 61.6% | 46.9% |
| Chr1 | 其他 | 1,368,941 | 4,098,325 | 503,848 | 36.8% | 12.3% |
| Chr12 | LTR | 6,716,202 | 6,713,555 | 5,729,963 | **85.3%** | **85.3%** |
| Chr12 | DNA | 3,300,406 | 4,133,964 | 1,906,022 | 57.8% | 46.1% |
| Chr12 | 其他 | 786,409 | 2,835,139 | 223,933 | 28.5% | 7.9% |

**核心结论 2：LTR 组的双向一致度不随密度下降，反而升高（78.3/81.3 → 85.3/85.3）。**

细桶看得更清楚（LTR 富集的染色体上，结果更好而不是更差）：

| 细桶 | Chr1 召回 / 精确率 | Chr12 召回 / 精确率 |
|---|---|---|
| LTR/Gypsy | 97.9% / — | **98.4%** / 95.3% |
| LTR/Copia | 95.1% / — | **96.4%** / 94.2% |
| LTR/unknown | 90.3% | 90.3% |

上一版报告说"Gypsy 双向 91–97% 是最硬的结论"。现在它更硬了：**在 LTR 最富集的染色体上达到 98.4%**。

`LTR/unknown` 的覆盖两边都是 90.3%——这是 MSU 自己笼统标注的部分，与 EDTA 的粒度差异无关。

## 4. EDTA 独有部分的构成：预测被验证

| 染色体 | TIR | Helitron | LTR（Gypsy+Copia+unknown） | LINE |
|---|---:|---:|---:|---:|
| Chr1 | 52.1% | 37.6% | **7.9%** | 3.8% |
| Chr12 | 45.3% | 39.5% | **12.4%** | 4.4% |

上一版报告写的是"EDTA 独有里 LTR 只占 4.1%"。**那个数字是单染色体库下的结果；
同一次运行内 LTR 份额是 7.9%（Chr1）与 12.4%（Chr12）。**

我在设计这次运行时预测："LTR 占比从 8% 涨到 15%，EDTA 独有的成分很可能跟着变"。
**预测成立**：LTR 在 EDTA 独有部分里的份额随染色体 LTR 富集度上升了约 4.5 pp。

但"TIR + Helitron ≈ 85–90%"这个主导结构没有变——**这是稳定的**，
也就是说"EDTA 的精确率缺口主要来自 DNA/TIR 与 Helitron"这条结论可以跨染色体引用。

## 5. 六项检查：结构层可复现，同源层随库变

### 5.1 逐染色体

| | Chr1 | Chr12 |
|---|---:|---:|
| intact 元件 | 1,659 | 1,074 |
| LTR 元件 | 218 | 202 |
| 分类器条目 | 230 | 201 |
| **C4 已定超家族覆盖** | **187/198 = 94.4%** | **163/175 = 93.1%** |
| C4 未定超家族（预期不分类） | 20/20 | 27/27 |
| C6 一致性/域冲突 | 23 | 30 |
| C2 内部区过短 | 24 | 19 |
| C3 TIR 数 / 匹配率中位 / 臂长中位 | 1,144 / 0.8182 / 16 bp | 680 / 0.8182 / 16 bp |
| C3 最低匹配率 | 0.6244 | 0.6547 |
| C3 完美反向重复 | 1 | 2 |
| C5 库层面跨类 | 29 | 28 |

C4 的差距（94.4% vs 93.1%）只有 **1 个元件的差别**（11/198 vs 12/175），
在 175–198 的样本上不足以称为"密度效应"。**结论：C4 的判据跨染色体成立。**

C3 的匹配率中位数**第 6 次出现同一个值 0.8182**，臂长中位 16 bp（六份数据：14/15/15/16/16/16）。
这仍然是 TIR-Learner 80% 阈值与最小 TIR 长度 10 bp 共同造成的投影，不是生物学保守性。

### 5.2 Chr1 的 run-to-run：这是本次最意外的收获

同一序列、两次独立运行、两套库：

| 指标 | 首次（单染色体库） | 本次（双染色体库） | 变化 |
|---|---:|---:|---|
| intact 元件 | 1,669 | 1,659 | −10（−0.6%） |
| LTR 元件 | 218 | 218 | **0** |
| C4 已定超家族 | 187/198 = 94.4% | 187/198 = 94.4% | **完全一致** |
| C4 未定超家族 | 20 | 20 | 0 |
| C6 | 23 | 23 | **0** |
| C2 | 24 | 24 | **0** |
| C3 匹配率中位 / 臂长中位 | 0.8182 / 16 bp | 0.8182 / 16 bp | **0** |
| **同源注释覆盖** | 37.83% | **39.42%** | **+1.6 pp** |
| **碱基召回** | 85.3% | **87.0%** | **+1.7 pp** |
| **碱基精确率** | 65.5% | **64.0%** | **−1.5 pp** |

**核心结论 3：六项检查在结构化层面几乎逐项复现，只有同源注释层随库大小变化。**

这个拆分很重要，它说明两件事：

1. **C1–C6 是稳定的判据**，可以作为回归基线——同一输入重跑，指标不动，
   所以任何差异都能当信号。这是做 A/B/C 置信度分级的前提（分级阈值必须远大于噪声底，
   而这里噪声底近似为 0）。
2. **召回率/精确率这类数字不是元数据，是"这份库 + 这条染色体"的属性**。
   引用 85.3% 或 87.0% 时必须同时说明库是怎么建的。**同一段序列，换个库规模，
   召回就涨 1.7 pp，精确率掉 1.5 pp。**

## 6. 顺带确认：`.mod.mod` 的根因有了日志级直接证据

上一版报告第 5.3 节把根因定为"基因组被归一化了两次"，依据是源码。本次运行日志给出了直接证据：

```
No encoding needed — all 2 IDs fit within id_len_max=12 (longest scaffold: 43270923 bp)
awk: fatal: cannot open file 'Oryza_sativa.Chr1_Chr12.fa.mod.pass.list'
```

LTR_retriever **明确判定"不需要编码"**，但产物仍然落到了 `X.fa.mod.mod.*` 下
（修复时复制的正是 `Oryza_sativa.Chr1_Chr12.fa.mod.mod.*`，`pass.list` 57,141 B）。

也就是说：**该分支执行后无条件把基因组名换成 `$genome.mod`，与是否真的编码无关。**
这不再是源码推断，而是运行时的自证。`>Chr1` 这种 4 字符 ID 会中招，
正是因为"不需要编码"也会写出并采纳那个文件。

## 7. 两个口径说明（引用数字时必看）

**① 42.73% 与 42.95% 的差**
EDTA 自报 `Total 55,757 bpMasked 30,248,422 = 42.73%`，分母是 70,788,168 bp
（比 FASTA 少 14,611 bp，它用的是清洗后的基因组）。本报告的并集计算是 30,411,... / 70,802,779 = 42.95%。
两者差 0.22 pp，来源是合并规则不同（`sum` 的条目数 55,757 少于 `anno.gff3` 的记录数 63,737）。
**跨染色体比较用脚本口径（内部一致）；对外引用 EDTA 的注释率写 42.73%。**

**② MSU 密度的两种算法**见第 0 节。凡引用密度，必须写明是 `bp_sum` 还是 `bp_union`。

## 8. 局限

1. **两条染色体，占基因组 19.0%**。没有中间密度点，无法排除非线性关系。
2. **密度与组成同时变化**。Chr12 的 Gypsy 份额（15.3%）远高于 Chr1（8.0%），
   所以"召回稳定"到底是"密度无关"还是"LTR 更富反而更好"，这两条无法分离。
   要分离需要第三条染色体——例如 Chr3（密度接近 Chr1 但组成不同）或 Chr4（密度接近 Chr12）。
3. **RepeatMasker 的 `general.working` 缺失仍在**（本次 filter 阶段报了 7 次）。
   注释率 42.73% 看似合理，但这条环境缺陷会压低召回，所以 87% 仍是**下限**。
4. **LINE 完全不可比**：MSU 在 Chr1/Chr12 上只注了 11.6 kb / 16.9 kb LINE，
   EDTA 的召回算出来是 21.7% / 8.7%，这个数没有解释意义。
5. **MSU 不可归类量两条染色体不同**（10.0% vs 6.6%），会影响召回的可比性，
   程度未量化。

## 9. 对课题的意义

**课题 2（基准与评估）**：水稻基准从 11.6% 扩到 19.0%，覆盖密度的两个端点。
更关键的是拿到了"库大小效应"的定量估计——**同一序列召回差 1.7 pp**。
以后做跨版本对比（2.2.2 / 2.3.0），这个数就是版本差异的对照基线：
小于 1.7 pp 的差异不能归因于版本。

**课题 1（工具线）**：
- C1、C4、C6 在两条染色体上成立，且 Chr1 的重跑逐项复现 → 判据可作为回归基线
- **run-to-run 噪声底 ≈ 0**，说明 A/B/C 置信度分级可以建立在很细的阈值上
- 仍未验证的是：C2 的最短内部区（本次 3 bp）、C5 的库层面跨类（57 条）是否随库规模放大

**下一步最该做的不是再加染色体，而是把这两条染色体的数据做成 A/B/C 分级的第一个测试集**
——分级需要"什么算噪声"这个前提，而它刚刚被测量出来了。
